# Dfinery React Native SDK

React Native 앱에서 Dfinery API를 사용할 수 있는 SDK입니다.

- [Dfinery User Guide](https://docs.dfinery.ai/user-guide)
- [Dfinery Developer Guide](https://docs.dfinery.ai/developer-guide/platform/reactnative)

## 요구 사항

- React Native 0.88.0+
- iOS 15.0+ (Xcode 27+)
- Android SDK 24+

## 의존성

### Android
- [io.dfinery:android-sdk 2.7.4](https://github.com/IGAWorksDev/dfinery-android-sdk)

### iOS (CocoaPods)
- [DfinerySDK 2.5.1](https://github.com/IGAWorksDev/dfinery-ios-sdk)
- [DfinerySDKServiceExtension 2.5.1](https://github.com/IGAWorksDev/dfinery-ios-sdk)

### iOS (SPM)
- [DfinerySDK 2.6.0](https://github.com/IGAWorksDev/dfinery-ios-sdk)
- [DfinerySDKServiceExtension 2.6.0](https://github.com/IGAWorksDev/dfinery-ios-sdk)
