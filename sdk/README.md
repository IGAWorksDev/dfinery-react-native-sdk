# Dfinery React Native SDK

This repository contains the javascript interface and native React Native functionality for the React Native plugins derived from the Dfinery Android and iOS SDKs.

- [Dfinery User Guide](https://docs.dfinery.ai/user-guide)
- [Dfinery Developer Guide](https://docs.dfinery.ai/developer-guide/platform/reactnative)

### iOS
- [DfinerySDK](./CHANGELOG.md)
- [DfinerySDKServiceExtension](./CHANGELOG.md)
